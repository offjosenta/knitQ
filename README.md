# KnitQ — счётчик рядов и органайзер проектов по вязанию

Офлайн-PWA для iPhone с интерфейсом в стиле Apple Liquid Glass.

## Публикация на GitHub Pages

1. Создайте новый репозиторий на GitHub (например, `knitq`) и привяжите его локально:
   ```bash
   git remote add origin https://github.com/<ваш-логин>/knitq.git
   git push -u origin master
   ```
2. Откройте репозиторий на GitHub → **Settings** → **Pages**.
3. В разделе **Build and deployment → Source** выберите:
   - **GitHub Actions** (рекомендуется — используется готовый workflow `.github/workflows/pages.yml`, который публикует только статические файлы приложения), **или**
   - **Deploy from a branch** → ветка `master`, папка `/ (root)`.
4. Через 1–2 минуты приложение будет доступно по постоянной ссылке:
   `https://<ваш-логин>.github.io/knitq/`

## Установка на iPhone (экран «Домой» и офлайн-режим)

1. Откройте ссылку `https://<ваш-логин>.github.io/knitq/` в **Safari** на iPhone (важно использовать именно Safari, не встроенный браузер мессенджера).
2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх в нижней панели Safari).
3. Пролистайте меню вниз и выберите **«На экран „Домой“»**.
4. Проверьте название **KnitQ** и нажмите **«Добавить»**.
5. Запустите **KnitQ** с рабочего стола iPhone один раз при включённом интернете, чтобы Service Worker (`sw.js`) закэшировал все файлы. После этого приложение работает полностью автономно даже в авиарежиме.

## Облачная синхронизация (GitHub Gist) за 1 минуту

Чтобы проекты, ряды и таймеры автоматически сохранялись в ваш приватный GitHub Gist и восстанавливались при переустановке иконки или на новом телефоне:

1. Откройте на GitHub страницу создания токена: **Settings → Developer settings → Personal access tokens → Tokens (classic)** → **Generate new token (classic)**.
2. В поле **Note** укажите, например, `KnitQ Sync`, в **Expiration** выберите **No expiration** (или удобный срок).
3. В списке прав отметьте **только одну галочку — `gist`** (Create gists) и нажмите **Generate token**.
4. Скопируйте полученный токен (`ghp_...`) и сохраните его в «Паролях» / Заметках.
5. В **KnitQ** откройте **Настройки → Облачная синхронизация (GitHub Gist)**, вставьте токен и нажмите **«Сохранить»**.

Дальше приложение само создаст приватный Gist `knitq-backup.json` (или найдёт уже существующий при вводе того же токена на новом устройстве) и будет автоматически синхронизироваться при открытии, изменениях и сворачивании.
