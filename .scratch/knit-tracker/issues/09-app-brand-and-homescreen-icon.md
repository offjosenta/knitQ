# 09: Логотип KnitQ в шапке и иконка рабочего стола iOS (сравнение B и C)

**What to build:** Проработка двух вариантов нового логотипа KnitQ (вариант B — минималистичная монограмма `Q` из нити, вариант C — вязаная лицевая петля в стиле Liquid Silver), визуальное сравнение обоих вариантов для выбора пользователем, обновление мини-иконки рядом с названием в приложении и генерация комплекта иконок для рабочего стола iPhone.

**Blocked by:** 06 (Единые дизайн-токены Liquid Glass, унификация кнопок/инпутов и терминология «Проект»)

**Status:** done

- [x] Подготовлены и показаны пользователю два визуальных варианта логотипа (вариант B: монограмма `Q` из нити и вариант C: вязаная петля в эстетике Liquid Silver).
- [x] Выбранный пользователем вариант применён для мини-иконки рядом с названием KnitQ в верхней панели приложения.
- [x] Сгенерированы обновлённые PNG-иконки для рабочего стола iPhone и PWA (`apple-touch-icon` 180×180, 192×192 и 512×512) в едином стиле с логотипом.
