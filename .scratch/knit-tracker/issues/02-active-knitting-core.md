# 02: Экран активного вязания, счетчик рядов, таймер и журнал

**What to build:** Рабочий экран для вязания со спицами в руках. Главный счетчик рядов начинается с 0, центральная часть экрана представляет собой гигантскую сенсорную зону: касание в любое место добавляет 1 ряд (`+1`) без необходимости целиться. Имеется аккуратная кнопка вычитания ряда (`-1`) и защита от случайного сброса. Таймер детали автоматически снимается с паузы при нажатии «+1 ряд», если вязальщица забыла включить его вручную. Нажатие на цифру текущего ряда открывает всплывающий «Журнал рядов» с точной хронологией каждого клика (время в формате ЧЧ:ММ:СС и дата), позволяя проверить, посчитан ли уже текущий ряд при вязании под сериал. Все данные непрерывно сохраняются в локальное хранилище телефона.

**Blocked by:** 01 (Каркас приложения, темы оформления и PWA)

**Status:** ready-for-agent

- [ ] Экран вязания содержит крупные высококонтрастные цифры текущего ряда с начальным значением 0.
- [ ] Огромная интерактивная область тапа позволяет увеличивать счетчик ряда касанием пальца или тыльной стороны ладони без точного прицеливания.
- [ ] Кнопка «-1» корректно уменьшает счетчик рядов, а сброс требует явного подтверждения.
- [ ] Таймер части автоматически запускается / возобновляется при клике «+1 ряд», если стоял на паузе.
- [ ] Клик по цифре ряда открывает модальное окно «Журнал рядов» со списком отметок времени каждого ряда.
- [ ] Виброотклик (Haptic feedback) по умолчанию отключен, в настройках присутствует тумблер включения.
- [ ] Все изменения рядов, таймеров и журнала мгновенно персистируются в локальном хранилище.
