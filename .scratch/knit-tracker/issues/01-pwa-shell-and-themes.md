# 01: Каркас приложения, темы оформления и PWA

**What to build:** Полноэкранное автономное веб-приложение (PWA) для iPhone 15, которое устанавливается из Safari на экран «Домой», открывается без рамок браузера, сохраняет работоспособность при полном отсутствии интернета (офлайн) и не дает экрану айфона затухать во время вязания (Screen Wake Lock). Приложение поддерживает мгновенное переключение тем оформления в настройках: «Liquid Silver & Titanium» (жидкий хром на темном фоне Space Gray), «Emerald & Violet Glass» (глубокое полупрозрачное темное стекло с неоновыми изумрудными и фиолетовыми акцентами) и «Light Minimal» (светлая тема).

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] Мета-теги для iOS Safari (`apple-mobile-web-app-capable`, `viewport-fit=cover`, безопасные зоны экрана) обеспечивают отображение на весь экран без полос браузера.
- [x] Манифест приложения (`manifest.json`) и иконка позволяют добавить приложение на домашний экран iPhone 15 в один клик.
- [x] Service Worker кэширует все ресурсы и обеспечивает 100% работу приложения в режиме офлайн (без подключения к интернету).
- [x] Система CSS-переменных и переключатель тем в настройках мгновенно переключают стили между «Жидким серебром», «Изумрудным стеклом» и «Светлой темой» с сохранением выбора пользователя.
- [x] Screen Wake Lock API предотвращает автоматическую блокировку и затухание экрана iPhone при открытом приложении.
