# 12: Автосинхронизация данных с приватным GitHub Gist

**What to build:** Автоматическая синхронизация всех проектов, статистики, таймеров и настроек с приватным GitHub Gist пользователя при открытии и сворачивании/закрытии приложения (при наличии интернета), чтобы данные не терялись при переустановке иконки PWA на iPhone или смене устройства и могли восстанавливаться по одному токену.

**Blocked by:** 11 (Публикация на GitHub Pages и офлайн-установка на iPhone)

**Status:** ready-for-agent

- [ ] В Настройках добавлен блок «Облачная синхронизация (GitHub Gist)» в стиле Apple Liquid Glass: ввод и сохранение GitHub Personal Access Token (с правом `gist`), отображение статуса/времени последней синхронизации (или «Офлайн» / ошибки) и кнопка ручной синхронизации «Синхронизировать сейчас».
- [ ] При первом подключении токена приложение автоматически находит существующий приватный Gist с файлом `knitq-backup.json` (если пользователь уже синхронизировался с другого устройства или переустановил иконку) либо создаёт новый приватный Gist.
- [ ] При открытии приложения (когда есть сеть и настроен токен) проверяется версия в Gist: если локальные данные ещё пустые/дефолтные или облачная копия новее, состояние автоматически восстанавливается из Gist без потери уже сделанной офлайн-работы.
- [ ] При сворачивании/закрытии приложения (`visibilitychange` → `hidden`, `pagehide`) и при изменениях (с дебаунсом, когда есть сеть) актуальный бэкап автоматически сохраняется в приватный Gist; в офлайне ошибки сети не мешают работе и не затирают локальные данные.
- [ ] Все сценарии синхронизации (поиск/создание Gist, сравнение меток времени, загрузка, выгрузка и офлайн-режим) покрыты автоматическими тестами, `npm test` и `npm run check` проходят без ошибок.
- [ ] В `README.md` добавлена короткая инструкция, как за 1 минуту создать GitHub Token с правом `gist` для синхронизации.
