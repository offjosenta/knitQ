# 0001. PWA вместо нативного iOS приложения

Приложение разрабатывается в формате Progressive Web App (PWA) с полной поддержкой офлайн-режима и сохранением на домашний экран iOS.

## Контекст и проблема
Пользователю требуется персональный счетчик петель для iPhone 15. Рассматривалась возможность сборки нативного приложения и установки «по проводу» (sideloading).

## Решение
Выбрана архитектура PWA (HTML/CSS/JS + Service Worker + Local Storage / IndexedDB) с добавлением через Safari на домашний экран iOS («На экран Домой»).

## Причины и компромиссы (Trade-offs)
- Установка по проводу без платного аккаунта Apple Developer ($99/год) требует переподписывания сертификатов каждые 7 дней, после чего приложение перестает запускаться.
- PWA работает бессрочно, бесплатно, не требует Mac и Xcode для разработки и устанавливается в один клик.
- PWA работает полностью автономно (офлайн) без доступа к интернету благодаря Service Worker.
- Компромисс: PWA на iOS не поддерживает нативные виджеты рабочего стола (WidgetKit), однако полноценно закрывает потребности экрана вязания и блокировки засыпания экрана (Wake Lock API).
