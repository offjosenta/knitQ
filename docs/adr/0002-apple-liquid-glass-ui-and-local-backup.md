# 0002. Дизайн в стиле Apple Liquid Glass и автономное резервное копирование

Интерфейс оформляется в эстетике Apple Liquid Glass (полупрозрачные карточки с размытием, темная тема по умолчанию, акценты изумрудного и фиолетового цветов), а данные хранятся автономно с функцией JSON-экспорта.

## Контекст и проблема
Пользователю важна лаконичность, премиальный дизайн Apple и комфорт для глаз при вечернем вязании в темной теме. Также требуется надежное сохранение данных без регистрации на серверах.

## Решение
1. Применен дизайн в стиле Apple (Glassmorphism / Liquid Glass: размытие подложек `backdrop-filter: blur`, скругления углов squircle, системные шрифты, глубокий темный фон #0d0f12 с изумрудными и фиолетовыми градиентными акцентами, переключатель темы в настройках).
2. Вибрация по умолчанию отключена (опциональный тумблер в настройках).
3. Данные сохраняются локально в `localStorage` / `IndexedDB`, а для защиты от потери создается функция экспорта/импорта файла резервной копии в формате `.json`.
