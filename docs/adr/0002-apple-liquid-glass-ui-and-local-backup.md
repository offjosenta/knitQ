# 0002. Дизайн в стиле Apple iOS 27 Liquid Glass и автономное резервное копирование

Интерфейс оформляется в эстетике **Apple iOS 27 Liquid Glass** (чистый OLED-чёрный фон в тёмной теме, матовое стекло, скругления squircle, удлинённые тумблеры-пилюли), а данные хранятся автономно с функцией JSON-экспорта.

## Контекст и проблема
Пользователю важна лаконичность, нативный современный дизайн уровня Apple iOS 27 и комфорт для глаз при вечернем вязании в тёмной теме. Также требуется надёжное сохранение данных без регистрации на серверах.

## Решение
1. **Единый визуальный стандарт — Apple iOS 27 Liquid Glass** (весь новый UI должен следовать ему без отклонений):
   - **Тёмная тема (`liquid-silver`, по умолчанию):** чистый OLED-чёрный фон экрана и модальных шторок (`#000000`), карточки `#1c1c1e` / `rgba(28, 28, 30, 0.88)` с верхним бликом, чёткая верхняя окантовка шторки (`1.5px solid rgba(255, 255, 255, 0.24)`), чтобы она не сливалась с чёрным фоном.
   - **Светлая тема (`light-minimal`):** системный светло-серый фон `#f2f2f7`, белые карточки `#ffffff`, лёгкое затемнение подложки (`rgba(15, 23, 42, 0.18)`) и мягкие естественные тени (`0 -8px 32px rgba(0, 0, 0, 0.08)`).
   - **Стекло, размытие и отступы:** `backdrop-filter: blur` на карточках и подложке модальных окон (при открытии шторки задний экран мягко размывается); верхний отступ `.app-container` учитывает `env(safe-area-inset-top)` + дополнительный запас (`+20px`), чтобы шапка не попадала в системный блюр iOS.
   - **Формы и контролы:** скругления squircle `24–26px`, разделители `0.5px`, удлинённые тумблеры-пилюли `64×28 px` с вытянутым овальным бегунком (`border-radius: 999px`) по образцу системных настроек iOS 27.
   - **Иконография:** минималистичный контур клубка со скрещёнными спицами в стиле Liquid Silver.
2. Вибрация по умолчанию отключена (опциональный тумблер в настройках).
3. Данные сохраняются локально в `localStorage` / `IndexedDB`, а для защиты от потери создаётся функция экспорта/импорта файла резервной копии в формате `.json`.
