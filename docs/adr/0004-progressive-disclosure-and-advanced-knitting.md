# 0004. Прогрессивное раскрытие интерфейса и расширенные инструменты вязания

Все расширенные функции (реглан, парные детали, учет мотков, маркеры рядов) скрыты по принципу Progressive Disclosure и не перегружают базовый сценарий вязания.

## Контекст и проблема
Пользователь начинает с простых изделий (шарф, шапка) и опасается перегруженного интерфейса («боюсь потеряться в приложении»). При этом в будущем планируется вязание носков, варежек, свитеров, топов и сумок, где требуются парные детали, ритмичные прибавки и заметки на ряды.

## Решение
1. Применен принцип **Progressive Disclosure (Прогрессивное раскрытие)**:
   - Базовый экран проекта и вязания остается ультра-минималистичным: только название, номер спиц, крупный счетчик рядов и таймер.
   - Все расширенные блоки («Правило прибавок», «Связать парную деталь», «Маркеры на ряды», «Учет мотков», «Калькулятор образца») скрыты в аккуратных сворачиваемых секциях или добавляются по явной кнопке «+ Добавить настройку».
2. При создании проекта предлагаются быстрые шаблоны:
   - *«Базовый»* (шарф, шапка, снуд) — чистый минимализм без лишних полей.
   - *«Парный»* (носки, варежки, митенки) — с готовой кнопкой парной детали.
   - *«Плечевой / Сложный»* (джемпер, кардиган, топ, реглан) — с расширенными частями и правилами прибавок.
3. Любое простое изделие можно в один клик превратить в сложное, добавив нужный блок.
